# 電動車アナトミーCT

代表的な電動車（BEV・HEV・PHEV）の内部構造を3Dで再現し、CTのように断面を見られるビューアーです。`index.html` 1ファイルで動きます。

## 使い方

- `index.html` をブラウザで開くか、GitHub Pages で公開して開きます。
- three.js（r147）と Google Fonts を CDN から読み込むため、インターネット接続が必要です。

## できること

- **パワートレインの切り替え**
  - BEV：床下に75 kWh級の電池、後輪をモーター1基で駆動
  - HEV：トヨタTHS II型（エンジン＋MG1・MG2＋動力分割機構、後席下に約1 kWhの電池）
  - PHEV：床下に約18 kWhの電池、前輪はエンジン＋2モーター、後輪はモーターで駆動する4WD
- **断面表示**
  - X（前後）・Y（左右）・Z（上下）の3軸それぞれを、両端から切るスライダー
  - 切り口は製図風の斜線（ハッチング）で表示
  - スラブ（薄切り）表示と、X軸方向の自動スキャン
  - 「正中で縦割り」「モーターを縦割り」「床下を水平断」「前軸で輪切り」などのプリセット
- **部品情報**
  - 部品をクリックすると、名前・役割・しくみ・代表的な数値・代表メーカーを表示
  - 部品一覧から選ぶと、その部品にズームしてほかを半透明に表示
- **表示の切り替え**
  - 標準表示とX線表示
  - 系統ごとの色分けと実物風の色
  - 分解（エクスプロード）表示
  - 系統ごとの表示・透過・非表示
  - BEVの電池セル形式（角形・円筒・ラミネート）

## 座標系と寸法

- 座標は ISO 8855 の車両座標系（X 前方・Y 左・Z 上）で、原点はホイールベース中央の路面です。
- 寸法の例: 全長4,600 × 全幅1,840 × 全高1,500 mm、ホイールベース2,750 mm、トレッド1,580 mm。

## 注意

- 形状と配置は、一般的な構成を簡略化した模式モデルです。特定の車種を再現したものではありません。
- 代表メーカーは公開情報にもとづく例示です。網羅や取引関係を示すものではありません。
